# Build with GitHub Actions

Upload the contents of this project folder to a GitHub repository, including `.github/workflows/build.yml`. Commit the files, then open the repository's **Actions** tab and select **Build Freecam Mod**. Run the workflow if it has not started automatically. When the build succeeds, download the `simple-freecam-jars` artifact from the completed workflow run.

The source has not been verified by a successful build yet. If the workflow fails, inspect the failed build log and fix compatibility errors before installing the mod.
